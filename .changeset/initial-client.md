Initial implementation of the NLM drug API client: RxNorm, Prescribable RxNorm, RxTerms, RxClass, DailyMed v2, and MedlinePlus Connect sub-clients with typed responses, injectable `fetch`, configurable base URLs (RxNav-in-a-Box support), request timeouts, and a typed `NlmApiError`. Also restores boolean `publishConfig.provenance`.
